# Ficha Forbidden Lands (online)

Ficha de personagem de Forbidden Lands para o TaleSpire, com rolagem pela bandeja de dados, painel do Mestre, iniciativa, ferimentos e magia.

Esta versão carrega a ficha da internet (GitHub Pages). Ela se atualiza sozinha: cada versão nova chega na próxima vez que você abrir o Symbiote, sem reinstalar. As fichas continuam salvas no seu TaleSpire, por campanha.

Guia ilustrado: https://github.com/erickhwk/forbiden-lands-symbiote/blob/main/docs/GUIA.md

Forbidden Lands é marca da Free League Publishing. Este é um projeto de fã, sem afiliação.
